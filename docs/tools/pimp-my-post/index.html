Pimp My Post

Editeur de post ameliore : coloration BBCode/HTML + formulaire assiste a partir de tes propres templates. Deux etapes pour l'installer, une troisieme facultative pour le configurer.

1. Charger le module

Administration > Modules > HTML & JAVASCRIPT > Gestion des codes Javascript (placement : toutes les pages). Colle :

<script type="module"> import { init } from "https://cdn.jsdelivr.net/gh/violette-bleue/pimp-my-forum@main/docs/js/modules/pimp-my-post.js"; init(); </script>

Le module charge lui-meme ce dont il a besoin (CodeMirror, son propre CSS) — rien d'autre a ajouter pour une installation minimale.

2. Ecrire tes templates

Un champ assiste se declare avec data-input sur la balise a remplir :

<!-- mode simple : cibles separees par des espaces --> <a data-input="href target text" href="" target="">texte</a> <!-- mode groupes : label@cible, label optionnel --> <a data-input="(Lien@href) (Cible@target) (@text)" href="" target="">texte</a>

Sucres disponibles sur la meme balise :

  • text / textarea — cible le textContent
  • class--groupe — groupe de classes exclusif ou multi (valeurs en config, voir plus bas)
  • data-label — en-tete du groupe de champs
  • data-label-text — intitule du champ texte
  • data-freezone="Titre" — emplacement et libelle de la zone libre

3. Configurer les libelles (facultatif)

Sans configuration, le module affiche le nom brut des attributs. Pour des libelles lisibles, colle un second bloc avant le script d'installation :

<script> window.PimpMyPost = { Config: { labels: { href: "Lien", "img href": "Lien direct vers l'image" }, selects: { "data-size": ["sm", { value: "lg", label: "Grand" }] }, classes: { layout: ["col1", { value: "col2", label: "Deux colonnes" }], // exclusif couleur: { mode: "multi", values: ["rouge", "bleu"] } // multi } } }; </script>

Chaque valeur de liste accepte une string ("val" — le libelle affiche sera "val") ou un objet { value, label }. Le value part dans le code genere, le label est purement d'affichage.

Cette page est provisoire : un configurateur visuel (a la maniere de Pimp My Toolbar) viendra la remplacer pour composer ces reglages sans toucher au JS.
