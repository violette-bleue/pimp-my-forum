Pimp My Tooltip

Infobulle custom en remplacement du title natif du navigateur (delai d'affichage nul, position suivant le curseur, style habille). Une etape pour l'installer, une seconde facultative pour la regler.

1. Charger le module

Administration > Modules > HTML & JAVASCRIPT > Gestion des codes Javascript (placement : toutes les pages). Colle :

<script type="module"> import { init } from "https://cdn.jsdelivr.net/gh/violette-bleue/pimp-my-forum@main/docs/js/modules/pimp-my-tooltip.js"; init(); </script>

Le module scanne toute la page a son chargement : chaque element portant un attribut title se voit retirer ce title (pour eviter le doublon avec l'infobulle native) et recoit l'infobulle custom a la place.

2. Regler l'affichage (facultatif)

Sans configuration, l'infobulle s'affiche sans delai, decalee de 14px sous le curseur, largeur max 260px. Pour ajuster, colle un second bloc avant le script d'installation :

<script> window.PimpMyTooltip = { Config: { selector: "[title]", // elements cibles delay: 120, // ms avant affichage offsetX: 14, // decalage horizontal (px) offsetY: 14, // decalage vertical (px) maxWidth: 260 // largeur max (px) } }; </script>

Cette page est provisoire : un configurateur visuel (a la maniere de Pimp My Toolbar) viendra la remplacer pour composer ces reglages sans toucher au JS.
